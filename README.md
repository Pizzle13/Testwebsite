# My Static Website

A modern, responsive static website built with HTML, CSS, and JavaScript. This website is designed to be hosted on GitHub Pages and features a clean, professional design with smooth animations and mobile responsiveness.

## Features

- Responsive design that works on all devices
- Modern and clean user interface
- Smooth scrolling navigation
- Mobile-friendly hamburger menu
- Animated sections on scroll
- Social media integration
- Project showcase section
- Contact information

## Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/Testwebsite.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Testwebsite
   ```

3. Open `index.html` in your browser to view the website locally.

## Customization

To customize the website for your needs:

1. Edit `index.html` to update the content
2. Modify `styles.css` to change the styling
3. Adjust `script.js` to modify the interactive features

## Deploying to GitHub Pages

1. Go to your repository settings on GitHub
2. Scroll down to the "GitHub Pages" section
3. Select the branch you want to deploy (usually `main` or `master`)
4. Save the settings and wait a few minutes for the site to deploy

Your website will be available at: `https://yourusername.github.io/Testwebsite`
